# 🚀 EscalaX

O **EscalaX** é uma aplicação desenvolvida para automatizar e facilitar o acesso, leitura e organização de escalas de voo, transformando processos manuais em uma experiência simples e eficiente.

🔗 Acesse o projeto: https://www.escalax.app.br/

---

## 📌 Sobre o projeto

O EscalaX nasceu de uma necessidade real de otimizar a visualização e gestão de escalas, eliminando etapas manuais e repetitivas.

A aplicação realiza automações de acesso, leitura de dados (incluindo PDFs) e organização das informações de forma clara para o usuário final.

---

## ⚙️ Tecnologias utilizadas

- **Frontend:** React + TypeScript  
- **Backend:** Node.js  
- **Outros:**
  - Integrações com APIs externas  
  - Automação de fluxos  
  - Manipulação e leitura de PDFs  
  - Serviços em nuvem (cloud)

---

## 🚧 Desafios enfrentados

Durante o desenvolvimento, alguns dos principais desafios foram:

- Implementação de fluxos de autenticação complexos  
- Automação de navegação em sistemas externos  
- Leitura e interpretação de dados em PDF  
- Tratamento de erros em fluxos assíncronos  
- Estruturação de uma arquitetura escalável  

Cada desafio exigiu estudo contínuo e diversas iterações até chegar em uma solução estável.

---

## 🎯 Objetivo

O objetivo do EscalaX é simplificar o acesso às escalas e melhorar a experiência do usuário através da automação e organização inteligente das informações.
